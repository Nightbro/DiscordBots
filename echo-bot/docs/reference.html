Echo Bot Reference

Discord bot for server audio — music playback, soundboard, per-user intro sounds, and TTS voice output. Runs on Raspberry Pi via PM2. Supports both ! prefix and / slash commands via discord.py hybrid commands.

Architecture

Three-layer design. Cogs handle Discord protocol. Utils contain all logic (no Discord types leak in). Data persists to JSON and audio files. Rule: cogs never touch discord.VoiceClient, discord.Embed, or JSON directly.

Typical command flow

sequenceDiagram
    participant U as User
    participant C as Cog
    participant N as Notifier
    participant V as VoiceStreamer
    participant D as Downloader

    U->>C: !play lofi beats
    C->>N: loading(ctx, "Resolving…")
    C->>D: resolve("lofi beats")
    D-->>C: Track{title, url, file_path}
    C->>V: play(track)
    V-->>C: queued / now playing
    C->>N: track_card(ctx, embed)
    N-->>U: send embed / TTS / react (per notify settings)

MusicCog cogs/music.py

Hybrid commands (prefix + slash). Checks the guild's uploaded library before searching online. Playlists are per-bot-instance (not per-guild) stored in data/playlists.json.

CommandAliasesDescription
!play <query>!pQueue a track (YouTube URL, Suno URL, or search term). Checks library first; shows a "switch to YouTube?" prompt for name matches.
!skip!sSkip the current track.
!pause—Pause playback.
!resume!unpauseResume paused playback.
!stop—Stop playback and clear the queue.
!replay!rpRestart the current track from the beginning.
!nowplaying!npShow the currently playing track card.
!queue [page]!qShow the playback queue (10 per page).
!clear—Clear the queue (keeps current track playing).
!remove <pos>!rmRemove a track by queue position number.
!shuffle—Shuffle the queue.
!join—Join the caller's voice channel.
!leave!disconnect, !dcLeave the voice channel and clear all state.
!playlist!plPlaylist group — bare invocation shows subcommand hint.
!playlist save <name>—Save current queue + playing track as a named playlist.
!playlist load <name>—Load a playlist into the queue.
!playlist list—List all saved playlists with track counts.
!playlist delete <name>—Delete a playlist.
!playlist show <name>—Show contents of a playlist (up to 20 tracks).
SoundboardCog cogs/soundboard.py

Upload audio SFX to a shared soundboard. Each sound has a name, an emoji (for the reaction panel), and a short trigger. Quick trigger: !shortname in chat plays a sound without using a subcommand — intercepted via on_message before registered commands.

CommandAliasesDescription
!sb add <name> [💥] [| short]!soundboard addAdd a sound (attach audio file). Name may contain spaces. Emoji and short trigger are optional — both are auto-assigned if omitted.
!sb remove <name>!soundboard removeRemove a sound and delete its audio file.
!sb play <name>!soundboard playPlay a sound in your voice channel.
!sb short <name> <new_short>!soundboard shortChange the short trigger. Last word is the new short; everything before is the sound name (no quotes needed for multi-word names).
!sb list!soundboard listList all sounds with emojis and short triggers.
!sb panel!soundboard panelPost a persistent reaction panel — react with an emoji to play that sound.
!<name or short>—Quick trigger via on_message. Tries full name first, then first word. Registered commands always take priority.
IntrosCog cogs/intros.py

Plays audio when users join a voice channel. Three trigger types: bot (when Echo joins), user (any user joins), @member (a specific member). Supports day-of-week overrides. Plays via VoiceStreamer.interrupt() — pauses music, plays, resumes.

CommandTriggerDescription
!intro set <trigger> [url]bot / user / @mentionSet the default intro. Attach audio or provide a URL.
!intro schedule <trigger> <days> [url]bot / user / @mentionDay-specific override. Days: MON, SAT,SUN, MON-FRI, WEEKDAY, WEEKEND.
!intro unschedule <trigger> <days>—Remove a day-specific override.
!intro clear <trigger>—Remove all intros for a trigger (and delete audio files).
!intro rename <trigger> <name>—Update the human-readable label for a trigger's default entry.
!intro list—List all intro triggers for this server.
!intro show—Show bot/user intro overview and global flags.
!intro trigger <trigger>bot / user / @mentionManually play an intro sound.
!intro autojoin <on|off>—Toggle bot auto-join when first user enters a voice channel.
TTSCog cogs/tts.py

Text-to-speech via edge-tts. Per-guild voice and rate settings stored in GuildConfig. Audio synthesized to a temp file in data/downloads/, played via interrupt, then deleted.

CommandAliasesDescription
!say <text>—Speak text in your voice channel.
!tts voice <name>—Set the TTS voice for this server. Use !tts voices to see options.
!tts voices [locale]—List available edge-tts voices, optionally filtered by locale prefix (e.g. en, sr). Shows first 20.
!tts rate <value>—Set speech rate, e.g. +10%, -20%, +0%.
!tts stop—Stop current TTS playback.
!tts show—Show current TTS voice and rate for this server.
LibraryCog cogs/library.py

Per-guild uploaded track library. !play <name> checks this before searching YouTube. Quota enforced per guild (configurable max tracks + max MB). Files stored in data/library/<guild_id>/.

CommandAliasesDescription
!save [name]!uploadSave an attached audio file. Name defaults to filename stem. Also works on a replied-to message.
!download <url|search>!dlResolve via YouTube, check for a similar track already in the library, then download and save. A two-button confirmation view appears when a match is found.
!download play <url|search>—Same as !download, then queues the track for immediate playback.
!library [query]!libBrowse library with dropdown picker + page buttons. With a name or #N, plays that track immediately.
!library play <query>!lib playPlay a track by name or #N.
!library remove <query>!lib deleteRemove a track by name or #N.
!library rename <query> <new name>!lib renameRename a track.
!library info <query>!lib infoShow details: duration, size, who added it, play count.
HelpCog cogs/help.py

Paginated help driven by the i18n locale system. 8 pages: overview, music, library, queue, intros, soundboard, tts, settings. Content changes with the guild's locale.

CommandAliasesDescription
!help [section]!hShow paginated help with Prev/Next buttons. Optional section jump: music, queue, intros, soundboard, tts, settings.
SettingsCog cogs/settings.py

Per-guild feature flags. Requires Manage Server permission. Settings persist in GuildConfig (JSON). All have sensible defaults in config.yaml.

Toggle settings

KeyDefaultWhat it controls
auto_joinconfig.yamlBot joins voice when the first user enters a channel.
auto_leaveconfig.yamlBot leaves voice when the last user exits.
notify_writetrueSend a text embed for command responses.
notify_sayfalseSpeak command responses via TTS when in voice.
notify_song_texttrueShow track card embed when a song loads.
notify_song_voicefalseSpeak the track title via TTS when a song loads.
notify_say_textfalseSend embed after !say (default: react only).
notify_say_voicefalseSpeak the "Speaking." confirmation after !say.

DevCog cogs/dev.py

Owner-only commands checked via bot.owner_id (from OWNER_ID env var). Prefix commands only — never slash, to avoid accidental public exposure. !version is the one public exception.

CommandAccessDescription
!reload <cog>OwnerHot-reload a cog and its util dependencies (no restart needed). Re-sync slash tree with !sync after if commands changed.
!restartOwnerGraceful shutdown — PM2 auto-restarts the process.
!sync [guild_id]OwnerSync slash command tree globally or to a specific guild.
!statusOwnerShow active voice connections, guild count, loaded cogs, uptime.
!cogsOwnerList all loaded extensions.
!versionEveryoneShow the running bot version from config.yaml.
DevlogCog cogs/devlog.py

Forwards WARNING-level+ log entries to a channel or DM. Per-guild opt-in. Batches entries (3s window, max 5 per message). The current_guild ContextVar is set on every event/command invocation so records are properly tagged.

InvocationAccessEffect
!devlog hereManage ServerForward this server's errors to the current channel.
!devlog here allOwnerAlso include unscoped (no guild) errors.
!devlog dmManage ServerForward this server's errors to your DMs.
!devlog offManage ServerDisable dev log for this server.
!devlog testManage ServerEmit a test log entry to verify routing.
!devlog here (in DM)OwnerSubscribe the owner DM to all servers' errors.

Utility Modules

All logic lives in utils/. No Discord type should leak into utils. Cogs are thin protocol adapters: parse input, call utils, present results.

ModuleKey exportResponsibility
utils/voice.py VoiceStreamer All voice interactions: join, leave, play, skip, stop, pause, resume, interrupt. Auto-leave on empty channel. Cogs never touch VoiceClient directly.
utils/message.py MessageWriter Centralized embed builder: success/error/info/track_card/queue_page/soundboard_panel. Color injected from config.COLOR. No inline discord.Embed() in cogs.
utils/notifier.py Notifier Response delivery router. Routes to text embed, TTS, or react-only based on notify_write / notify_say per-guild settings.
utils/downloader.py Downloader Pluggable source handler: YouTube (yt-dlp), Suno (direct clip API → MP4 with AAC audio). Routes on URL pattern or falls back to YouTube search. Caches downloads.
utils/guild_state.py GuildState, Track Typed per-guild runtime state: queue, voice_client, current_track, interrupted_track, TTS queue. Created on first access via bot.get_guild_state().
utils/guild_config.py Module functions Per-guild persisted settings: auto_join, auto_leave, notify_*, locale, voice_language, TTS voice/rate. JSON-backed via BaseConfig.
utils/persistence.py BaseConfig, PlaylistConfig Atomic JSON load/save base class. PlaylistConfig, IntroConfig, and SoundboardConfig inherit from it. Atomic write (write temp + rename).
utils/i18n.py t(key, guild_id, **kw) Locale lookup with keyword interpolation. Reads locale YAML files from locales/. Per-guild locale resolved from GuildConfig. Fallback to en. Supported: en, sr.
utils/audio.py AudioFileManager Validate extension against AUDIO_EXTS, receive Discord attachment, save to disk. Shared by Intros, Soundboard, and Library cogs.
utils/library.py Module functions Per-guild uploaded track library: slugify, quota check (tracks + MB), probe_duration via ffprobe, find/resolve/track_list. Metadata in library_config.json.
utils/intro_config.py Module functions Per-guild intro assignments: default entries and day-specific schedule overrides. Resolves best file for a trigger + current day of week.
utils/soundboard_config.py Module functions Soundboard metadata: add/remove/find/get sounds, emoji pool management, short trigger lookups. Schema: {name: {emoji, file, short}}.
utils/reactions.py ReactionHandler Yes/no confirm flow and reaction panel dispatcher. Extracted from 40+ lines of copy-paste in music-bot.
utils/devlog.py DevlogHandler, GuildContextFilter Logging handler routing WARNING+ records to per-guild targets. ContextVar-tagged by guild. Batches to avoid spam. Not hot-reloadable (ContextVar split).
utils/cleanup.py purge_old_files() Deletes files older than 7 days from data/logs/ and data/downloads/ on bot startup.
utils/shutdown.py Helpers Graceful shutdown utilities for PM2-managed restart cycle.
utils/config.py Constants Loads config.yaml at import. Exposes all typed path constants, timeouts, limits, feature flags, and VERSION. All DATA_DIR-derived paths are created on import.
